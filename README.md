# edu.pwa-app: учебное PWA-приложение

Клиентское веб-приложение на **React + Vite + TypeScript**, которое поэтапно превращается в **Progressive Web App (PWA)**. Цель проекта — изучить создание PWA на практике: manifest, service worker, офлайн-кэш, установка на устройство и смежные возможности платформы.

## Стек

- **Frontend:** React 19, TypeScript, Vite
- **Стили:** CSS (доступен SCSS через `sass-embedded`)
- **Менеджер пакетов:** pnpm

## Быстрый старт

```bash
pnpm install
pnpm dev
```

Приложение откроется на `http://localhost:5173` (порт по умолчанию Vite).
