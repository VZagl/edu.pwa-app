# UI-конвенции

## Общие принципы

- **Адаптивность:** mobile-first (телефон — типичный сценарий установки PWA); на планшете и десктопе layout должен выглядеть нормально, без простой растяжки мобильной вёрстки.
- **Доступность:** семантические теги (`main`, `nav`, `button`), видимый focus, `aria-label` для icon-only кнопок.
- **Язык UI:** русский (строки не хардкодить в разброс — группировать по экранам; i18n — при появлении отдельного шага).

## Модальные окна и overlay

При использовании модалок (dialog):

- Закрытие по Escape и явная кнопка «Закрыть»
- Блокировка прокрутки body при открытой модалке
- Focus trap — при подключении headless-библиотеки следовать её API

Overlay-блоки, которые **не должны** закрывать модалку при клике, помечать атрибутом `data-avoid-modal-dismiss` и учитывать в обработчике «click outside»:

```typescript
const shouldCloseOnInteractOutside = (element: Element) => !element.closest('[data-avoid-modal-dismiss]');
```

## PWA-специфичный UI

- **Offline:** явный индикатор (banner/badge), не только молчаливый сбой сети
- **Обновление SW:** ненавязчивый баннер с действием «Обновить»
- **Install:** кнопка «Установить» + текст-подсказка для браузеров без `beforeinstallprompt`

## Чеклист
