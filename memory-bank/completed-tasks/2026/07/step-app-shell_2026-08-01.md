## Задание

Базовая разметка: header, main, простая навигация. Заменить стартовый шаблон Vite на оболочку учебного PWA (название проекта, место под контент уроков). Стили — только SCSS.

**Цель:** приложение имеет узнаваемую оболочку; контент уроков рендерится в main.

## Результат

Заменён стартовый шаблон Vite на учебную оболочку PWA: stacked layout (`header` → `nav` → `main`), навигация через React Router v8 (library mode), маршруты `/` и catch-all 404. Стили мигрированы на SCSS (`index.scss` + `App.scss`, BEM `app-shell__*`). TDD: `App.test.tsx` (3 теста), обновлён `e2e/smoke.spec.ts`. Verify: lint, build, `pnpm test --run` (6 тестов), `pnpm test:e2e` — OK.

**Для пользователя:** приложение имеет узнаваемую оболочку с заголовком, навигацией «Главная» и областью контента вместо шаблона Vite.
