# Memory Bank: Style Guide

Краткая выжимка для агента. Детали UI: `docs/project/ui-conventions.md`.

## Язык и тон

- UI и ответы ассистента по проекту — **русский**
- Учебный тон: коротко, по делу, без «магии» — объяснять PWA-понятия в UI при появлении уроков

## Вёрстка

- Mobile-first: база под узкий viewport (телефон), на планшете и десктопе — полноценный адаптив, без «растянутой мобильной» вёрстки
- Семантические теги: `header`, `nav`, `main`, `button`
- Видимый focus; `aria-label` для icon-only кнопок

## Стили в коде

- Только SCSS рядом с компонентом; глобальные — `index.scss` / оболочка в `App.scss`
- Не подключать UI-kit по умолчанию
- Форматирование — Prettier (порядок CSS-свойств, organize imports/attributes)

## PWA UI (когда появятся шаги)

- Offline — явный индикатор (banner/badge)
- Обновление SW — ненавязчивый баннер «Обновить»
- Install — кнопка «Установить» + подсказка для браузеров без `beforeinstallprompt`

## Модалки (при появлении)

- Escape + кнопка «Закрыть»
- Блокировка scroll body
- Элементы, не закрывающие по outside-click: `data-avoid-modal-dismiss`
